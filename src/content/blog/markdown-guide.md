這篇列出寫文章時常用的 Markdown 語法，也順便測試網站的排版。

## 文字樣式

**粗體**、*斜體*、~~刪除線~~、`行內程式碼`、<kbd>Ctrl</kbd> + <kbd>C</kbd>、<mark>螢光標記</mark>。

連結：[站內連結](/archive/)、[外部連結](https://astro.build)（外部連結會自動開新分頁，並加上 ↗ 符號）。

## 提示框

用 GitHub 的語法，在引用區塊第一行加上 `[!類型]`：

> [!NOTE]
> 一般的補充資訊。

> [!TIP]
> 實用的小技巧。

> [!IMPORTANT]
> 讀者必須知道的重點。

> [!WARNING]
> 需要特別注意的地方。

> [!CAUTION]
> 可能造成問題的危險操作。

## 程式碼

程式碼區塊標上語言就會有語法高亮，右上角有複製按鈕：

```ts
import { getCollection } from 'astro:content';

const posts = await getCollection('blog');
console.log(`共有 ${posts.length} 篇文章`);
```

```bash
npm run new -- "我的新文章" --category tech
```

```yaml
title: 範例
tags: [a, b]
```

## 圖片

把圖片放在文章同一個資料夾，用相對路徑引用，建置時會自動壓縮、轉檔：

```md
![替代文字](./my-image.png)
```

圖片加上標題（引號內的文字）就會在下方顯示說明：

```md
![替代文字](./my-image.png "這段文字會顯示在圖片下方")
```

## 數學公式

用 `$$` 包起來。寫在句子中間是行內公式，例如 $$E = mc^2$$；獨立成段就是區塊公式：

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

> [!NOTE]
> 單一個 `$` 不會被當成公式，所以寫「一杯咖啡 $3、一份早餐 $5」不會出問題。

<summary>點我展開</summary>

</details>

## 註腳

這句話需要附上出處[^1]，也可以有第二個註腳[^note]。

[^1]: 註腳內容會顯示在文章最下方。
[^note]: 註腳標記可以是任意文字。
